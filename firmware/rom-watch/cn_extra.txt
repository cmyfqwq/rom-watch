# cn_extra.txt —— 「我自己的标题里要用到的字」放这儿（2026-09-30 加）
# ============================================================================
# 为什么需要它：
#   固件的标题（DFLT_TITLE，网页/OLED/串口屏三处共用）是**可改**的 ✓，
#   但屏上的字是从**字模表**（cn_font.h）里查的 ⇒ **表里没有的字会画成空方框** ✗✓。
#   字模表默认只包含 rom-watch.ino 里出现过的汉字 ⇒ 你把标题改成一个"固件里从没出现过的字"，
#   那个字就没有字模 ✗。
#
# 怎么用：
#   1. 把标题里要用、而固件里可能没有的字，写在**这个文件里非注释的行**上（一行、几行、一串都行）
#      ★注意：以 # 开头的行会被忽略（所以你在上面看到的中文只是说明文字，不会被取模 ✓）
#   2. 重跑取模脚本（它会自动扫 rom-watch.ino 加上这个文件，重新生成 cn_font.h ✓）
#   3. 重新编译 + 上传（或用 OTA 推）
#
# 举例（把这行前面的 # 去掉就生效，四个字是"盘署测试"）：
# 盘署测试
#
# 说明：
#   · 每多一个字大约多占 16px(32B) + 24px(72B) = 104 字节 flash（很便宜 ✓）
#   · 这个文件留空（或只有注释）完全没问题 —— 脚本会跳过 ✓
#   · 只想"改显示的文字、不重新编译"：开网页 →「监测设置 → 标题」直接改 ✓
#     （但那种情况下也得保证字在表里，所以字模还是要按上面第 1~3 步加一遍 ✓）
# ============================================================================
