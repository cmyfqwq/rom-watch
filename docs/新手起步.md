# 新手起步：从零把 rom-watch 装起来

> 这份文档假设你**从没碰过单片机**：会复制粘贴命令，但不知道「杜邦线」「I2C」是什么。
> 每一步都写清楚了；遇到问题先跳到第 8 节**对号入座**。
>
> **这东西是什么**：一块十几块钱的 ESP8266 小板子 + 一块小 OLED 屏，
> 盯着你的网盘目录 / GitHub 仓库有没有出新版本 —— **有新版本就亮灯 + 屏上换字 + 网页变红**；
> 刷完点一下「我已刷 ✓」，它就安静下来。

**名词速查**（先扫一眼，后面就看得懂了）

| 词 | 人话 |
|---|---|
| ESP8266 / D1 mini | 那块指甲盖大小的**板子**，能连 WiFi，本身没有屏幕 |
| OLED | 那块**小屏**，显示版本号和状态 |
| 杜邦线 | 一头是塑料插母（或插针）的彩色软线，**插上去就行**，不用焊接 |
| I2C | 屏和板子说话的**两根线**：一根送数据（SDA）、一根打拍子（SCL） |
| 烧录 / 刷固件 | 把程序从电脑**灌进板子**；灌一次，断电也不丢 |
| 水位线 | 你已经确认过的版本 —— 比它旧的都不会再提醒你 |

## 1. 你要买什么

| 要买的 | 买哪个**不踩坑** | 参考价 |
|---|---|---|
| **ESP8266 开发板** | 认准 **WeMos D1 mini**（或任意 ESP8266 开发板）。板载 USB 芯片是 CH340 或 CP2102 都行 | ~¥15（README 里写的"15 块钱的 ESP8266"） |
| **0.96″ OLED 屏** | 认准 **I2C 接口、4 个针脚、SSD1306 / SSD1315、地址 0x3C** | 参考量级 ¥10~30（待确认，以你下单时为准） |
| **Micro-USB 数据线** | ★ 必须是**能传数据**的线，不能是"只充电"的线 —— 这是「电脑认不到板子」的第一大原因 | 参考量级 ¥5~10 |
| **杜邦线 母对母 ×4~8** | 板子和屏上都是排针，所以买**母对母**（插母） | 参考量级 ¥3~10 |
| （可选）TJC 串口屏 | 不接也能用。要买就买 **TJC 系列、通讯口 3.3V**、配独立 5~12V 电源 | 待确认（尺寸差价很大） |

**三个最容易买错的点**

- ⚠️ **别买 SPI 版的 OLED**（7 个针脚那种）—— 本固件走 I2C，只要 4 个针脚的。
- ⚠️ **别买 5V 的屏**：0.96″ 这种多数**只吃 3.3V**（VCC 接板的 `3V3`，不是 `5V`）。
- ⚠️ 0.91″（**128×32**）那种小屏也能用，但要改一个开关 `OLED_SMALL 1` 并**重新烧录**（见第 9 节）。

> ★ 价格只是**量级参考**（待确认）—— 不同店铺、不同批次差很多，下单时以实际为准。

## 2. 接上（看接线图）

**接线图：[docs/接线图.svg](接线图.svg)** —— 上图是「最小接线」，下图是「可选串口屏」。

### 2.1 最小接线：只要 4 根线

| OLED 屏上的脚 | 插到板子上的 | 说明 |
|---|---|---|
| `GND` | **GND** | ★ 共地，必须接 |
| `VCC` | **3V3** | ⚠️ **别接 5V** |
| `SDA` | **D2** | I2C 数据 |
| `SCL` | **D1** | I2C 时钟 |

> ★ **按脚上的名字接，不要按位置接** —— 不同模块这 4 个脚的排列顺序不一样。
> ★ 板子上的丝印找 `3V3` / `GND` / `D1` / `D2` 四个字就行，不用管其它脚。

### 2.2 插错了会怎样（对号入座）

| 插错了 | 会怎样 |
|---|---|
| `SDA` 和 `SCL` 接反 | 屏不亮或花屏 —— 联网后在网页扫 I2C 扫不到 `0x3C` |
| `VCC` 接到 5V | ⚠️ 多数 OLED 模块只吃 3.3V，接 5V 有**烧屏**风险 |
| `GND` 忘了接 | 屏**一个字都不显示**（看着像坏了，其实只是没共地） |
| 任何一根线接到 **D6** | ⚠️⚠️ **板子可能直接起不来** —— 见下面红框 |
| 屏上字是**空方框** | 不是接线问题，是标题里的字不在字模表里（见第 9 节） |

> ⚠️⚠️ **串口屏的任何一根线都不要接 D6（GPIO12）**
> D6 是 ESP8266 **开机时判断 flash 电压**的脚，被串口占着可能**直接起不来**。
> 默认接线（D5 / D7）已经避开它了 —— **改接线时别改回去**。

### 2.3 接好之后先通电看看

插上 USB，屏上应该先出现一页「**系统自检**」（上面写着 显示屏 / 配置 / 按键 / 总线 / 网络）。
**能看见字 = 这 4 根线接对了** ✓ —— 这一步还没烧固件也可能亮，所以很适合先验接线。

## 3. 烧固件（把程序灌进板子）

### 3.1 先做这一步：配好你的 WiFi（见第 4 节）

`config.h` 是"你的私有配置"。仓库里只有样板，**没有这个文件也能编**（编出来是"开机走 AP 配网"的固件）。
想让板子一开机就自己连上 WiFi，**先按第 4 节把 config.h 建好，再来烧录**。

### 3.2 然后跑两条命令（新手就用这个）

在**仓库根目录**（就是有 `README.md` 和 `tools\` 的那一层）打开 PowerShell：

```powershell
pwsh -File tools\setup.ps1          # 装环境（第一次跑）
pwsh -File tools\flash.ps1          # 编译 + 烧录（会自动找串口）
```

| 脚本 | 干什么 | 什么时候跑 |
|---|---|---|
| `tools\setup.ps1` | 准备编译环境（装 ESP8266 工具链和屏的库） | **只有第一次**跑，或者换了电脑才跑 |
| `tools\flash.ps1` | 编译 + 烧录，**会自动找串口** | 每次改了代码/配置，要更新板子时跑 |

> ★ 这两个脚本**已经在仓库里了** ✓（`tools\setup.ps1` / `tools\flash.ps1`）—— 名字、参数就是上面这样；
> 想看细节可以打开脚本看开头的注释块，或跑 `pwsh -File tools\setup.ps1 -Help` ✓

### 3.3 手动兜底（不想用脚本的人）

```powershell
# ① 装工具链（一次性；本仓库实测 esp8266 3.1.2）
arduino-cli core install esp8266:esp8266
arduino-cli lib install "ESP8266 and ESP32 OLED driver for SSD1306 displays"

# ② 编译
arduino-cli compile --fqbn esp8266:esp8266:d1_mini firmware\rom-watch

# ③ 烧录（把 COM3 换成你实际的串口）
arduino-cli upload  --fqbn esp8266:esp8266:d1_mini -p COM3 firmware\rom-watch
```

**串口是几号？** 设备管理器里看「端口 (COM 和 LPT)」，或者跑 `python tools\ota.py find` 让工具自己找。

## 4. 第一次配网（两种，选一种）

### 方式 A：填 `config.h`（★ 推荐）

```powershell
cd <仓库路径>\serial-screen\firmware\rom-watch
copy config.example.h config.h
```

然后编辑 `config.h`，改这几行：

```c
#define PVT_WIFI_SET   1                     // 1 = 开机就写死这套 WiFi（推荐）
#define PVT_WIFI_SSID  "你的WiFi名"           // ★ 只能填 2.4G 的 WiFi
#define PVT_WIFI_PASS  "你的WiFi密码"
```

| 注意 | 说明 |
|---|---|
| ★ 只支持 **2.4G** | ESP8266 连不上 5G 频段的 WiFi |
| ★ 顺便把口令改掉 | `config.h` 里加一行 `#define OTA_PASSWORD "换成你自己的"` —— 源码里那个默认口令是**公开的**，同网段的人能刷你的板子 |
| ⚠️ `config.h` 是你的私有文件 | 里面是 WiFi 密码和服务器地址，`.gitignore` 已排除，**别手滑提交** |

### 方式 B：开机走 AP 配网（不用填 WiFi）

把 `PVT_WIFI_SET` 留 **0**（或者干脆没有 `config.h`），烧进去之后：

| 步骤 | 做什么 |
|---|---|
| ① | 板子自己开一个热点，名字是 **`ROMWatch-<芯片号>`**（**开放、无密码**） |
| ② | 手机/电脑连上这个热点 |
| ③ | 浏览器打开 **`http://192.168.4.1/`** |
| ④ | 页面上填 WiFi 名和密码 → 保存 → 板子重启连网 |

> 已经连上网之后想换 WiFi：网页上点「**重新配网**」也能回到这个热点模式。

## 5. 找到板子的 IP

板子连上 WiFi 后，用它的 IP 打开网页面板。**三种找法**：

| 方法 | 怎么做 |
|---|---|
| ① 串口日志（最准） | 开机日志里有一行 `[BOOT] rom-watch ... http://<板子的IP>/` —— 那个地址就是 ✓ |
| ② 工具找 | `python tools\ota.py find` |
| ③ AP 模式 | 配网热点下网页面板固定在 **`192.168.4.1`** |

> ★ **固件已经做了**：开机联网成功之后，**OLED 上会亮 2.6 秒这个 IP** ✓
> （写的是「已联网」＋ IP ＋「浏览器打开」——新手不用翻串口日志就能找到板子 ✓）
> 串口日志里也一定会打印（`[BOOT] … http://<IP>/`），两种方式随便挑 ✓
>
> 提示：**这里故意不给你示例 IP** —— 板子的地址取决于你家路由器，照抄别人的例子是连不上的 ✗

## 6. 配数据源（网页「监测设置」）

打开 `http://<板子的IP>/`，找到「**监测设置**」卡片，选一个数据源，填完点【保存设置】，再点【立即检查】。

### 6.1 三种数据源，各一个填法

| 数据源 | 服务器 | 路径 | 取值键 | 时间键 | 请求方式 |
|---|---|---|---|---|---|
| **OpenList 目录**（网盘） | `alist.example.com` | `/public/roms` | `name` | `created` | POST |
| **GitHub Release** | `api.github.com` | `/repos/OWNER/REPO/releases/latest` | `tag_name` | `published_at` | GET |
| **自定义 JSON** | `api.example.com` | `/version.json` | `version` | `updated_at` | GET |

> 选好数据源后，**取值键 / 时间键 / 请求方式会自动填好**（在「高级」里能看到），你只要填服务器和路径，然后**记得点【保存设置】**。

### 6.2 两个必须记住的坑

| 坑 | 怎么绕 |
|---|---|
| **「路径」不总是"请求路径"** | OpenList 的请求路径**恒定**是 `/api/fs/list`，你要盯的目录走 POST 请求体 —— 页面上按预设填就行，不用管 |
| **GitHub 有两条硬规矩** | ① 必须带 `User-Agent`（固件已经带了 ✓）；② 未登录**限流 60 次/小时/IP** ⇒ **轮询间隔别小于 10 分钟**（默认 600 秒是安全的） |

## 7. 用起来（就三个动作 + 板上一颗键）

### 7.1 网页上三个按钮

| 按钮 | 干什么 | 会不会"一直安静下去" |
|---|---|---|
| **我已刷 ✓** | 推进**水位线**：这个版本算你处理完了 | ✓ 比它旧的都不会再提醒 |
| **跳过这版** | 只压住**这一个**版本 | ✗ 出了更新的版本还会提醒 |
| **👀 我知道了（关灯）** | **只把报警灯摁灭**，不改水位线、也不等于跳过 | ✗ 出更新的版本还会再亮 |

### 7.2 板载 FLASH 键三种手势

| 手势 | 等于网页上的 |
|---|---|
| **短按一下**（40 毫秒 ~ 1.5 秒） | 我已刷 ✓ |
| **按住 1.5 ~ 3 秒**，松手 | 跳过这版 |
| **按住 ≥ 3 秒** | 请求下载（★ 这是唯一的下载触发方式） |

> ★ 板载键**没有**「我知道了（关灯）」这个手势 —— 要关灯请在网页上点那个按钮。
> ⚠️ 板上那个 **RST 键是硬复位**，按了就重启，**固件读不到它**，不能当按钮用。

## 8. 装不上 / 不亮 怎么办（对号入座）

| 现象 | 先看这里 |
|---|---|
| **电脑找不到串口（认不到板子）** | ① 换一根**能传数据**的 USB 线（"只充电"的线最常见）② 装 USB 驱动（CH340 或 CP2102） |
| **OLED 不亮 / 花屏** | ① 接线：`SDA`/`SCL` 是不是反了、`GND` 有没有接 ② 联网后打开 `/i2c` 扫一下，正常应看到 `0x3C` ③ 扫不到就试 `#define OLED_ADDR 0x3D` |
| **屏上字是空方框 / 缺笔画** | 字模表里没有这几个字 ⇒ 见第 9 节（`cn_extra.txt` + 重跑取模脚本 + 重编上传） |
| **找不到 IP / 网页打不开** | ① 串口日志里的 `[BOOT] ... http://…/` ② WiFi 是不是 **2.4G** ③ AP 模式下面板在 `192.168.4.1` |
| **数据源一直失败（抓不到数据）** | ① `/rom` 里的 `lastErr` 和「调试：最近响应片段」会直接告诉你原因 ② GitHub 报 403 ⇒ 多半是**限流**（间隔调大）|
| **板子反复重启** | ① `/log` 看「上次跑到阶段」＋启动次数（黑匣子存在 RTC 内存里，异常重启不丢）② 查有没有线接到 **D6** ③ 串口屏是不是**从板子上取电**了 |

> 通用兜底：`python tools\ota.py serial --sec 20` 看串口日志；
> `/log` 里的「本次自检」五项（显示屏 / 总线 / 按键 / 配置 / 网络）哪一项是 ✗ 一目了然。
> **完整排错表 → [docs/接线与适配.md](接线与适配.md) 第 6 节。**

## 9. 想改点东西

| 想改什么 | 改哪里 | 要不要重编重烧 |
|---|---|---|
| **改标题**（网页 / OLED / 串口屏三处共用） | 网页「监测设置 → 标题」随时能改 | ✗ 不用 |
| 改标题，但**有字模表里没有的新字** | 把新字写进 `firmware/rom-watch/cn_extra.txt` → 重跑取模脚本 `gen_cn_font.ps1` | ✓ **要**（不跑就画成空方框） |
| 换成 **0.91″ 小屏**（128×32） | `config.h` 里 `#define OLED_SMALL 1` | ✓ 要 |
| 屏的地址是 **0x3D** | `config.h` 里 `#define OLED_ADDR 0x3D` | ✓ 要 |
| 换 I2C 引脚 | `config.h` 里 `#define PIN_OLED_SDA …` / `PIN_OLED_SCL …` | ✓ 要 |
| 换串口屏接线 | `config.h` 里 `#define PIN_TJC_RX …` / `PIN_TJC_TX …`（★**别用 D6**；波特率不用改，开机自动探测） | ✓ 要 |
| 换板子 | 环境变量 `ROMWATCH_FQBN=esp8266:esp8266:nodemcuv2`（★换板子后引脚编号可能变，顺手核对接线） | ✓ 要 |
| 干脆不接屏 / 不接 OLED | 编译开关 `-DUSE_TJC=0` / `-DUSE_OLED=0` | ✓ 要 |

> ★★ **改接线只改 `config.h`** —— 不要把引脚写回 `rom-watch.ino`。
> 写回主文件有两个后果：① 开源/分享时你的私有值泄露；② 下次别人改 `config.h` 会「改了不生效」，排查被带偏。
>
> **详细步骤（换板子 / 换屏 / 换数据源 + 完整排错）→ [docs/接线与适配.md](接线与适配.md)**
> **所有可配置项的注释样板 → [config.example.h](../firmware/rom-watch/config.example.h)**
